<objective>
## Goal
Adelka napíše po slovensky, čo chce realitke povedať; appka pripraví taliansky email (predmet + text) so slovenským prekladom. Adelka ho upraví a odošle sama cez svoj emailový klient alebo skopíruje.

## Purpose
PRD cieľ 5 a §5.4: AI nikdy neodosiela nič sama.

## Output
API route na draft, komponent MessageDraft na detaile inzerátu.
</objective>

<acceptance_criteria>

## AC-1: Draft zo zámeru
```gherkin
Given detail inzerátu
When Adelka napíše zámer (napr. "mám záujem, chcem obhliadku v septembri") a ťukne "Pripraviť správu"
Then zobrazí sa editovateľný taliansky predmet a text a slovenský preklad
And správa obsahuje odkaz/identifikáciu inzerátu a podpis Adelky
```

## AC-2: Nič sa neodošle automaticky
```gherkin
Given pripravený draft
Then server nikdy nič neodosiela
And jediné akcie sú "Otvoriť v e-maile" (mailto s upraveným textom) a "Kopírovať"
And UI výslovne hovorí, že správu odosiela Adelka sama
```

## AC-3: Validácia a chyby
```gherkin
Given prázdny alebo príliš dlhý zámer, neznámy inzerát alebo chýbajúci AI kľúč
Then API vráti 400/404/503 so slovenskou správou a UI ju zobrazí
```
